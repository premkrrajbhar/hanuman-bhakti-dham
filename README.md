# Hanuman Bhakti Dham [![Version](https://img.shields.io/badge/version-v1.0.0-blue.svg)](./CHANGELOG.md)

Hanuman Bhakti Dham is an Android application developed using Flutter and WebView. It provides users with a convenient way to access the Hanuman Bhakti Dham website directly from their Android devices through a dedicated mobile application.

The application integrates the existing website into a Flutter-based Android app, offering a simple and accessible mobile browsing experience.

## Features

- **WebView Integration** – Displays the Hanuman Bhakti Dham website within the Android application.
- **Website Access** – Allows users to access website content through a dedicated mobile app.
- **Internet Connectivity** – Loads online website content using an active internet connection.
- **Android Compatibility** – Designed to run on Android devices.

## Technologies Used

- **Flutter** – Framework for developing the Android application.
- **Dart** – Programming language used for application development.
- **WebView** – Displays the existing website inside the application.
- **Android SDK** – Tools and libraries for Android application development.

## How to Use

- **Step 1: Install the Application** – Download and install the Hanuman Bhakti Dham APK on your Android device through [here](https://github.com/premkrrajbhar/hanuman-bhakti-dham/releases/download/v1.0.0/app-release.apk).
- **Step 2: Open the Application** – Launch the application from your device.
- **Step 3: Access the Website** – The application loads the Hanuman Bhakti Dham website inside the WebView.
- **Step 4: Browse Content** – Navigate through the website directly within the application.

## How to Run Locally

- **Step 1: Clone the repository:**

```bash
git clone https://github.com/premkrrajbhar/hanuman-bhakti-dham
```

- **Step 2: Navigate to the project folder:**

```bash
cd hanuman-bhakti-dham
```

- **Step 3: Install Flutter dependencies:**

```bash
flutter pub get
```

- **Step 4: Run the application:**

```bash
flutter run
```

## Build APK

To generate a release APK, execute the following command:

```bash
flutter build apk --release
```

The generated APK will be available at:

```text
build/app/outputs/flutter-apk/app-release.apk
```
